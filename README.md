# 📚 Projeto HTML & CSS — Display

Projeto desenvolvido para estudar e praticar a propriedade `display` do CSS, explorando como diferentes valores alteram o comportamento e o posicionamento dos elementos em uma página.

## 🎯 Objetivo

O objetivo deste projeto é aprender, na prática, como funciona a propriedade `display` e entender as diferenças entre seus principais valores.

### Conceitos estudados

* `display: block`
* `display: inline`
* `display: inline-block`
* `display: flex`
* `display: grid`
* `display: none`

## 🛠️ Tecnologias

* HTML5
* CSS3
