# 📚 Estudo de CSS `display`

Projeto desenvolvido para estudar a propriedade **`display` do CSS**, entendendo como cada valor altera o comportamento e o posicionamento dos elementos na página.

## 🎯 Objetivo

Explorar os principais valores da propriedade `display` na prática, observando suas diferenças e casos de uso.

## 📌 Displays estudados

### `display: block`

O elemento ocupa toda a largura disponível e começa em uma nova linha.

**Exemplos:** `div`, `section`, `p`, `h1`.

```css
.elemento {
  display: block;
}
